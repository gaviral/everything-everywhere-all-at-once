# Thought & work

Enable **Thought & work** in Features, then open its view. It starts off. All code,
styles and focused checks live in this folder; no shared app files change.

The view holds your latest placed capture, or a deliberately chosen older one,
beside this connection's helper jobs. Keep a higher-level intention in the local
text box. Holding a thought supplies review context, not proof a job was requested
from it. Ownership and parent relationships are only those reported by the core.
No helpers are launched and no model or microphone is started by this view.

Select a job to inspect its reported output. Coding artifacts use the existing
host-only `/helper-result` endpoint with a server-owned opaque result identity.
Diffs remain read-only proposals. Execution, validation, review and application
are separate: a local version-specific reading mark proves none of the others.
Queued, failed, partial, dry-run, stopped and simulated work keep their states.
With no jobs, a clearly labelled interactive example supplies readable content.

Return to exact capture uses the host's source-checked navigation and preserves
the capture draft. Held words, intent, filter, chosen job and version review marks
survive a jump and return within this map/participant visit through plugin state.
Late jobs and thoughts do not replace the selection. A changed or missing capture
keeps its held words with a disabled return and an explanation. New visits get
separate state. This is visit memory, not durable shared queue ownership or
universal task completion.

Run `node ui/src/bricks/concurrent-work/check.mjs` from the repo root. It performs
scoped TypeScript, an isolated production build and browser behavior checks with
a synthetic host and proposal response on port 4387. It checks example/live
states, exact source return, draft/filter/selection preservation, late arrivals,
version review, code inspection, escaped output, host refusal, disconnection,
source changes, keyboard navigation and desktop/phone reflow. It does not prove
live model execution, physical TV readability, or applied changes.

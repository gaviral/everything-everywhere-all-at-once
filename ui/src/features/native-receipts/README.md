# Native receipt view

Export contract: `nativeReceiptsFeature` in `index.tsx` exposes `id`, `label`, `defaultEnabled: false`, `createVisit`, and `Component`. `createReceiptVisit(initialOperations, adapter?)` starts off and does not call the adapter until enabled. Mount `<NativeReceipts visit={visit} />`. Retain the visit in the host across navigation; call `dispose()` only when discarding it. The host must preserve the default off switch. Off stops only the owned observer, ignores late deliveries, and preserves records, selected identity and detail state. This contract has no execution method.

`ReceiptAdapter.subscribe` injects complete operation snapshots and returns its own cleanup. The adapter owner supplies approved display fields and an opaque, non-private operation alias, stable across status changes. A reused alias cannot change provider, origin or requested fields. Raw diagnostic properties are discarded; receipt references never render. Obvious account addresses and local paths are rejected in display fields, but this is not a general private-data classifier: the host must supply approved text. Do not pass account identifiers as operation aliases.

Confirmation requires a validated receipt with the same operation alias, provider, origin and confirmed outcome. A status claim without matching evidence resolves to unknown. Synthetic confirmation resolves to `synthetic-preview` and says no reminder was created. Native confirmation reports only what the supplied native receipt confirms; this view does not independently inspect Apple accounts. Receipt timestamps must be canonical UTC ISO timestamps with milliseconds. Requested due dates remain display text so the host can preserve their timezone meaning.

Parts: `ReceiptInput` validates and copies injected input; `ReceiptState` resolves truthful wording; `ReminderPreview` renders requested fields; `EvidenceDetail` renders provenance and limits; `ReceiptReturn` owns the visit, selection and observer lifecycle. `NativeReceipts` composes those parts. Inline results plus a separate evidence view retain context without introducing a modal. Returning restores focus to the evidence button. Text labels convey status without relying on color.

Scoped synthetic preview: serve `ui` with the existing Vite dependency and open `/src/features/native-receipts/preview.html`. The preview controls use only local fixtures. Run `node scripts/native-receipts-check.mjs` with the existing UI dependencies available. The check uses ephemeral loopback ports and its own Chrome PID, retains screenshots and its disposable browser profile, and performs no native execution.
